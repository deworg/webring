Create and manage webrings on your WordPress site.

== Description ==

Create and manage webrings on your WordPress site with a dedicated custom post type for member websites. You can optionally organize entries with categories to keep your webrings structured and easy to maintain.

The plugin also provides a block for displaying the HTML snippet visitors can use to join or link to your webrings, plus a block that lists all websites currently included in a webring.

== Screenshots ==

4. Websites in a webring displayed in a grid with features images
